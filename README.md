# SL CLUB - VIP Gala Invitation

Official VIP Grand Opening invitation application built with **Vue 3**, **Tailwind CSS v4**, and **Vite**.

## Features

- **Vue 3 Composition API (`<script setup>`)**: Fully reactive UI, interactive countdown timer, tier selection, and modal dialog.
- **Tailwind CSS v4 + Custom Design System**:
  - Custom dark theme with luxury gilded accents (`primary: #f2ca50`, `primary-container: #d4af37`, `secondary: #d4c78f`).
  - Native Khmer typography support: Kantumruy Pro, Battambang, Siemreap, and Playfair Display.
  - Material Symbols Outlined icons.
- **Interactive Capabilities**:
  - Live countdown ticker in Khmer numerals (`០-៩`).
  - VIP ticket tier selector with reactive price synchronization.
  - Persistent sticky bottom booking bar.
  - Interactive VIP reservation modal with transition animations.
  - Mobile bottom navigation bar.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Production Build
```bash
npm run build
```

### 4. Preview Build
```bash
npm run preview
```
